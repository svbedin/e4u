# История версий E4U

## 0.2.0 — 28.10.2026

- Голоса: в настройках только два — лучший женский и лучший мужской английский голос устройства
  (естественные и онлайн-голоса первыми, британский раньше американского).
- Убраны «Сохранить прогресс в файл / Загрузить из файла» (решение владельца).

## 0.1.0 — 28.10.2026

Первая версия, на основе Slovko 2.49.0.

- Название **E4U** (*easy for you, English for you*), адрес e4u.slovko.win, свой цвет (бирюзовый) и значок.
- Интерфейс на русском, словацком и украинском; произношение — английские голоса устройства (британский, затем американский).
- **Глаголы:** 103 глагола (60 неправильных), *to be*, Present Simple, Present Continuous, Past Simple; третья форма — A2.
  Неверные варианты — типичные ошибки (*goed, falled, stoping*).
- **Существительные:** 120 слов, артикль *a / an*, множественное число (*children, knives, cities, tomatoes*).
- **Фразы:** 97 фраз и 24 диалога по 8 темам A1 с переводом на 3 языка; все режимы Slovko, диктант на английском.
- **Грамматика:** 9 правил (to be, Present Simple, Present Continuous, Past Simple, can / must / have to, a / an / the и
  множественное число, there is / some / any / much / many, in / on / at, my / your / ’s).
- Клавиатура QWERTY с апострофом; *isn't* и *isn’t* считаются одинаково.
- Сервер, вход по коду, тестеры, письма, турнир, напоминания, сбои, файл прогресса — как в Slovko; своя политика доступа «E4U testers».
- `npm run check` — проверка английских данных и переводов; `npm run screens` — снимки экранов E4U.
