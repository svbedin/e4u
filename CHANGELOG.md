## 0.12.0 — 01.11.2026

- **Новый раздел «Мой учебник»** (первый на главной): выбираешь учебник и урок, который сейчас проходишь, — и тренируешь
  его слова (перевод, письмо, пары) и грамматику (предложения с пропуском). Пока Complete Key for Schools (A2), уроки 1–4:
  семья, числа, Present Simple, наречия частоты; дом, комнаты, мебель, время, Present Continuous, have got;
  еда, a cup of / a slice of, some / any, how much / many, a few / a little; одежда, магазины, прилагательные,
  Present Simple и Continuous, too / enough. Уроки 5–14 в меню — с пометкой «скоро».
  Из учебника взяты только темы, списки слов и порядок грамматики; предложения и переводы свои (`sections/book/data.js`).
- **Наречия (A2) — новый этап в «Прилагательных»:** как? slow → slowly, easy → easily, careful → carefully,
  good → well, fast / hard / early / late не меняются; среди неверных вариантов — ловушки hardly и lately
  (у них другое значение). 36 наречий, все записаны явно (`ADV` в `adj/data.js`), в таблице прилагательных — строка «наречие».
  У тех, кто уже выбирал этапы, наречия включаются один раз сами. Новые прилагательные: careful, careless.
- **«Что нового» после обновления:** тот, кто уже занимался, один раз видит на главной карточку «Что нового в версии …»
  (2–3 пункта, кнопка «Понятно»); пропустил несколько версий — видит только последнюю; новичкам не показывается.
  Текст — `NEWS` в `core/news.js`, переписывается при каждом выпуске (`npm run check` не пропустит старый).
- **«Обновить сейчас»:** если новая версия скачалась, пока приложение открыто, на главной — плашка «Есть новая версия …»
  с кнопкой (перезапуск на новой версии, прогресс сохраняется). Раньше она включалась только при следующем запуске.

## 0.9.0 — 01.11.2026

- **Вход по коду закончился (через 7 дней) — кнопка «Войти по коду»** на главной: страница входа Cloudflare
  (e-mail → код → снова в приложении, прогресс сохранён). Раньше установленное приложение открывалось из памяти телефона
  и код не просило. Новый `sw.js` при закончившемся входе очищает сохранённые файлы — при следующем запуске Cloudflare
  попросит код; для этого `e4u.slovko.win/sw.js` открыт в Cloudflare Access без входа. Сервер: `GET /api/signin`.
- **Темы фраз и слова уроков свёрнуты:** в меню раздела одна строка «Темы уроков — все ▾» (или выбранные номера: 3, 7);
  нажатие раскрывает список тем.
- **Напоминание о тренировке дня — время на барабане:** часы (06–23) и минуты (00, 15, 30, 45), время сохраняется,
  когда барабан остановился (раньше — только 17:00 … 21:00).
- **Одно нажатие — одно действие:** повторное нажатие той же кнопки в течение 0,4 с и нажатие в первые 0,3 с на новом экране
  не засчитываются; буквы экранной клавиатуры — без ограничения.
- **Фразы с пропуском:** подсказка под рамкой больше не сдвигает строку; слово перед пропуском и точка после него
  переносятся вместе с ним.
- **Быстрее загрузка:** шрифты WOFF2 только с нужными буквами (полные — в `fonts-src/`).
- **Планшеты и компьютеры:** новая проверка `npm run devices`.

## 0.1.0 — 28.10.2026

Первая версия, на основе Slovko 2.49.0.

- Название **E4U** (*easy for you, English for you*), адрес e4u.slovko.win, свой цвет (бирюзовый) и значок.
- Интерфейс на русском, словацком и украинском; произношение — английские голоса устройства (британский, затем американский).
- **Глаголы:** 103 глагола (60 неправильных), *to be*, Present Simple, Present Continuous, Past Simple; третья форма — A2.
  Неверные варианты — типичные ошибки (*goed, falled, stoping*).
- **Существительные:** 120 слов, артикль *a / an*, множественное число (*children, knives, cities, tomatoes*).
- **Фразы:** 97 фраз и 24 диалога по 8 темам A1 с переводом на 3 языка; все режимы Slovko, диктант на английском.
- **Грамматика:** 9 правил (to be, Present Simple, Present Continuous, Past Simple, can / must / have to, a / an / the и
  множественное число, there is / some / any / much / many, in / on / at, my / your / ’s).
- Клавиатура QWERTY с апострофом; *isn't* и *isn’t* считаются одинаково.
- Сервер, вход по коду, тестеры, письма, турнир, напоминания, сбои, файл прогресса — как в Slovko; своя политика доступа «E4U testers».
- `npm run check` — проверка английских данных и переводов; `npm run screens` — снимки экранов E4U.
