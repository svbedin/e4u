# E4U — инструкции для Claude Code

E4U (*easy for you, English for you*) — игровой тренажёр английского языка (PWA) с уровня A1. Владелец и автор: Serg.
Все права защищены (`LICENSE`). Сделан на основе кода Slovko (`C:\Users\Sergiy\Documents\Slovko`), но это **отдельный
проект**: своя папка, свой git, свой Worker и свои тестеры. Правки в одном проекте не переносятся в другой сами.
Общайся с владельцем по-русски; он понимает и украинский. Объясняй просто: владелец не программист.

## Что это

- Адрес: **e4u.slovko.win** (поддомен домена Slovko). Цвет — бирюзовый (#0E7A6B), значок «E4U».
- Интерфейс на 3 языках: русский (`ru`), словацкий (`sk`), украинский (`uk`) — в этом порядке (по алфавиту английских
  названий, `LANGS` в `i18n.js`). Английского интерфейса нет: язык изучения не дублируется.
- Раздел «Глаголы» (A1): 103 глагола (60 неправильных); этапы *to be* (am / is / are), Present Simple (he works),
  Present Continuous (I am working), Past Simple (went, was / were); третья форма (have gone) — A2.
- Раздел «Существительные» (A1): 120 слов; артикль *a / an*, множественное число (в т. ч. men, children, knives).
- Голос: в настройках два английских голоса — лучший женский и лучший мужской (естественные / онлайн-голоса первыми,
  британский раньше американского) — `pick()` в `core/speech.js`.
- Раздел «Фразы» (A1): 97 фраз и 24 диалога по 8 темам A1, написанных для E4U; режимы: Викторина, Письмо, Найди ошибку,
  Собери фразу, Перевод, Диалог, Диктант (с английским голосом).
- «Тренировка дня», турнир, напоминания (push), отчёты о сбоях, экран «Грамматика» (9 правил) — как в Slovko.

## Главные правила

1. **Телефон прежде всего.** Всё проверяй на ширине ~390 px, светлая и тёмная тема (цвета только через токены в `css/app.css`).
2. **Каждая строка интерфейса — на всех 3 языках** (`npm run check` это проверяет).
3. **Английский должен быть верным.** Формы глаголов и существительных записаны явно. Неверные варианты в фразах должны быть
   неверны для данного перевода. Если не уверен — скажи владельцу.
4. **Авторские права.** Каждый новый файл начинается с шапки `/*! E4U — <назначение> · Copyright (c) 2026 Serg. All rights reserved. */`.
   Фразы, диалоги и правила пишутся для E4U; чужие тексты, упражнения и картинки не копируем.
5. **Без сборки и без внешних CDN.** Чистый JavaScript (ES-модули), всё в `www/`. Без фреймворков и npm-зависимостей без согласия.
6. **Прогресс** — только через `www/js/core/store.js`.
7. **Не удаляй и не переписывай файлы владельца без спроса.** Перед крупными изменениями — короткий план.
8. **Никаких секретов в коде.** Ключи — только в Cloudflare (`wrangler secret put`); их вводит владелец.
9. **Политика доступа — «E4U testers»** (`POLICY_NAME` в `wrangler.jsonc`). Не «Testers»: так называется политика Slovko,
   и экран «Тестеры» E4U начал бы менять список Slovko. Лимит Cloudflare Access — 50 человек на весь аккаунт (вместе со Slovko).

## Устройство кода

```
www/js/main.js                точка входа
www/js/core/                  store, router, i18n (ru / sk / uk), ui, sound, speech (английские голоса en-GB / en-US), util, push, errors
www/js/games/engine.js        игровые режимы; клавиатура QWERTY с апострофом ’ (' и ’ считаются одинаковыми)
www/js/screens/               главная и настройки (screens.js), грамматика (grammar.js + grammar-data.js), тестеры, статистика, турнир, конфиденциальность
www/js/sections/verbs/        data.js: [base, he/she, past, past participle, -ing, ru, uk, sk, флаги a / i]; index.js; strings.js
www/js/sections/nouns/        data.js: [единственное, множественное или -, a | an, ru, uk, sk, флаги a / i]; index.js; strings.js
www/js/sections/phrases/      data.js: [тема, фраза с {ответ|подсказка|неверные}, ru, uk, sk, порядок слов]; DIALOGS: [тема, реплика, ответ, неверные, ru, uk, sk]
www/js/sections/daily/        «Тренировка дня»
worker/                       сервер Cloudflare (вход, тестеры, письма, турнир, статистика, push) — общий со Slovko по устройству
```

## Команды

```
npm start          локальный сервер: http://localhost:8080 (если занят Slovko — PORT=8095 npm start)
npm test           проверка данных и переводов + офлайн-тест сервера
npm run screens    снимки экранов на 390 px, светлая/тёмная тема, ru / sk / uk (screens:quick — светлая, ru)
npm run release    новый номер офлайн-кэша и список файлов в www/sw.js
npm run deploy     выложить на Cloudflare (после настройки по README.md)
npm run vapid      ключи напоминаний (запускает владелец, один раз)
```

## Порядок выпуска версии

1. `npm test`; `npm run screens` (только данные — `npm run screens:quick`), снимки просмотреть.
2. `npm run release`.
3. `CHANGELOG.md`, версия в `www/js/config.js` и `package.json`.
4. Коммит на русском, `git push` — резервная копия в закрытом репозитории https://github.com/svbedin/e4u.
5. `npm run deploy`.
