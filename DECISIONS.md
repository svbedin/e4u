- **28.10.2026 — отдельное приложение на поддомене Slovko.** Адрес e4u.slovko.win, название E4U (easy for you, English
  for you), интерфейс ru / sk / uk, уровень с A1, тестеры новые (отдельная политика Access «E4U testers»). Код — копия
  Slovko 2.49.0 в отдельной папке и отдельном git; общая часть (движок, сервер) дальше развивается в каждом проекте отдельно.

  (отправитель на домене slovko.win), база D1 `e4u`, хранилище KV `TESTERS` (свои, не общие со Slovko).
- **Будущие аккаунты** — Supabase, как решено для Slovko (`Slovko/DECISIONS.md`).
- **Содержание** — пишется для E4U (фразы, диалоги, правила); чужие учебники не копируются.
